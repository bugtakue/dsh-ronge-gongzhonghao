# 发布前检查清单

## 内容

- [ ] 标题是结论，≤22 字；
- [ ] 前三屏给完答案（点位/时间/催化或等价三要素）；
- [ ] 全文 2500–3500 字，6–8 屏；
- [ ] 没有"先说/本文/只做/下面/接下来/换句话说/综上"；
- [ ] 没有首先/其次/因此/然而/但是；
- [ ] 每节只讲一件事，小标题是句子；
- [ ] 没有重复结论；
- [ ] 幽默 ≤3 处，方法段保持正经；
- [ ] 文末有免责声明（如涉及投资/医疗/法律）。

## 排版

- [ ] 顶部没有绿色/深色大块；
- [ ] 没有左侧彩色边条；
- [ ] 正文仿宋 17px，行高 1.95；
- [ ] 关键数字有淡金高亮（10–20 处）；
- [ ] 结论卡是淡金底、无彩色边框；
- [ ] 图片 6 张以内，750px 宽；
- [ ] 图注 12px 灰，图内文字手机可读；
- [ ] 小标题金色编号 + 沙线；
- [ ] 所有元素 `text-align:left`。

## 微信

- [ ] HTML 复制粘贴后图片正常；
- [ ] 结构检测无致命项（有 start/end 警告可忽略）；
- [ ] 手机预览字号、行距正常；
- [ ] 标题/摘要/封面/原创/标签已设置。

## 最后

- [ ] 读一遍，删掉任何"像 AI 写的"句子；
- [ ] 把第一段念出来，像人话再发。

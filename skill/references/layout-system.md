# 公众号排版系统

## 1. 字体（去 AI 味的关键）

| 用途 | 字体 | 说明 |
|---|---|---|
| 正文 | 仿宋 `STFangsong / FangSong` | 公文感、书写感，不像系统默认 |
| 标题 | 宋体 `Songti SC / STSong` | 与正文反差，不靠大字号 |
| 数字 | Georgia | 与汉字不同源，像排过 |
| 禁止 | PingFang 正文、圆体、优设标题黑、渐变字 | 一眼 AI |

字号：正文 17px；标题 22px；小标题 23px；图注 12px；meta 12px。行高 1.95，段距 22px。

## 2. 颜色

```
纸底   #FAF7EF
墨色   #1F2723
松绿   #23453A
金色   #B58B3E
铁锈红 #A6472E
沙线   #E4D8BF
淡金底 #FBF3DA（结论卡/引文）
高亮   #F5E4A8（行内重点）
```

## 3. 组件

### 结论卡（开头）

淡金底、无彩色边框、"本 文 结 论"小字、3 行大字，关键数字行内高亮。

### 行内高亮

`==3200–3420==` → 淡金底 + 加粗。全篇 10–20 处，只给数字和判断。

### 小标题

金色编号 + 宋体标题 + 1px 沙线。编号用 `— 01 —`，不要大色块。

### 引文/金句

淡金底整块，宋体 19px。

### 图

- 750px 宽（手机版），图注 12px 灰；
- 一图一结论：标题是结论，kicker 说明属于哪节；
- 图内中文用仿宋，数字 Georgia；
- 真实数据优先，K线用 OHLC。

## 4. 禁止

- 顶部绿色/深色大块头；
- 左侧彩色边条（border-left）；
- 圆角卡片堆叠；
- 渐变、阴影、emoji；
- 1200px 图直接缩放；
- 居中大标题 + 居中正文。

## 5. WeChat 兼容

- 全部内联样式；
- 每个元素显式 `text-align:left`（避免微信报 start/end）；
- 不要 flex/grid 关键布局（微信可能吃掉），用简单块级；
- 图片 base64 方便单文件复制，但粘贴后仍要检查是否上传成功；
- 不用 `<style>` 里复杂选择器，全部写在元素上。

## 6. 移动版图规范

- 画布 750×H；
- 标题 26–30px，正文标注 ≥11px；
- 一图最多 3 个标注，标签贴线；
- 留白 ≥ 32px；
- 来源线右下角 10px。

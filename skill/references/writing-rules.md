# 去 AI 味写作规则

> 目标：读起来像一个懂行的人随手写的，不是模型生成的。

## 1. 最先删的：meta 话

只要一句话在"说这篇文章自己"，就删：

- 先说清楚 / 先说结论 / 本文 / 下面 / 接下来 / 只做一件事 / 只问一句
- 值得注意的是 / 换句话说 / 也就是说 / 综上所述 / 归根结底
- 我们先看 / 让我们 / 本节将 / 最后想说的是
- "不是A，而是B" 的对仗（尤其是排比三连）

改法：直接从事实开始。

**改前**：大多数推演都会偷懒：找一个理由、算一个点位、给一个日期，然后就结束了。
**改后**：网上答案大多很懒。找个理由。算个点位。给个日期。完事。

## 2. 连接词全砍

删：首先、其次、再次、另外、此外、同时、与此同时、因此、所以、然而、但是、不过、于是、接着、然后。

靠句子顺序和短句承接，不靠连接词。

**改前**：因为美联储重启加息，所以美债收益率上行，因此成长股估值承压。
**改后**：美联储重启加息。美债收益率上行。成长股估值承压。

## 3. 一段 1–3 句，一句一个意思

- 长句拆短，逗号改句号；
- 允许一句话成段；
- 数字单独成句：`5月13号。上证4242.57。`
- 少用"的、了、着、过"堆叠，少用"进行、实现、具有、存在"。

## 4. 小标题是句子

- ✅ 这轮跌的，不是"大盘"
- ✅ 底不是一个数，是一个分布
- ✅ 这个区间怎么来的
- ❌ 市场分析 / 结论 / 数据说明 / 风险提示

## 5. 结论先行

开头三行内给完：

```
点位：3200–3420。中位3413。80%区间2907–3623。
时间：20–90个交易日。
催化：外部缓和 > 关税休战 > 国内政策。
```

读者看完前三屏就能走，这是公众号的礼貌。

## 6. 幽默只放 2–3 处

放在转折处，一句就收：

- "人家打了个喷嚏。我们直接进ICU。"
- "跟算命摊差不多。还不用担责任。"
- "之前降了那么多次，怎么还跌。"

不要每段都抖机灵。方法段、数字段保持正经。

## 7. 禁用词表

赋能、抓手、闭环、生态、链路、颗粒度、对齐、沉淀、复盘、打法、组合拳、护城河、底层逻辑、长期主义、不确定性、范式、维度、张力、叙事、锚点、体感、水位、斜率、中枢（除非确有必要）。

## 8. 结构模板

```
标题（结论，≤22字）
副标题（方法/代价）
导语（3行答案）
01 发生了什么（事实 + 图）
02 结论是什么（分布/区间 + 图）
03 怎么算的（四步，每步2–3句）
04 条件/情景（图）
05 催化/变量（图）
06 怎么验证（3–5条）
最后（一句话 + 互动）
```

## 9. 字数控制

- 目标 2500–3500 字；
- 超过 4000 字先砍方法论；
- 一屏手机 ≈ 400–500 字，全文控制在 6–8 屏；
- 一节不超过 500 字，超过就拆或删。

## 10. 改稿顺序

1. 删 meta 和连接词；
2. 长句拆短；
3. 结论提到开头；
4. 砍重复；
5. 小标题改成句子；
6. 最后才润色。

# 禁用词表（AI 味黑名单）

> 原则：**能删就删，不能删就换成具体动作/数字/人**。
> 下面按"为什么 AI"分组。带 ⚠️ 的是高频雷区，写完先搜这几个。

## A. 元话语（文章说自己）⚠️

先说 / 先说结论 / 先说清楚 / 先说两句、本文 / 本篇 / 这篇文章、下面 / 接下来 / 接下来我们 / 下面我们、本节 / 本章、让我们 / 我们来、只做一件事 / 只问一句、一句话总结 / 一句话概括、综上 / 综上所述 / 总之 / 总的来说 / 简而言之、换句话说 / 也就是说、值得注意的是 / 需要指出的是、不难发现 / 显而易见 / 众所周知、事实上 / 实际上 / 某种程度上 / 从某种意义上说、可以说 / 不难看出 / 由此可见、归根结底 / 说到底 / 本质上 / 核心在于 / 关键在于 / 重点在于 / 问题在于 / 答案在于。

**处理**：直接删。从事实开始。

## B. 连接词（句子的胶水）⚠️

首先 / 其次 / 再次 / 最后（列举用）、一方面 / 另一方面、与此同时 / 同时（句首）、此外 / 另外 / 除此之外、然而 / 但是 / 不过、因此 / 所以 / 于是 / 从而 / 进而 / 因而 / 故而、不仅如此 / 更重要的是 / 进一步 / 接着 / 然后 / 随后。

**处理**：删掉，句子直接并排。靠顺序承接，不靠连接词。

## C. 抽象大词（不说人话）⚠️

赋能 / 抓手 / 闭环 / 生态 / 链路 / 颗粒度 / 对齐 / 沉淀 / 复盘 / 打法 / 组合拳 / 护城河 / 底层逻辑 / 长期主义 / 不确定性 / 范式 / 维度 / 张力 / 叙事 / 锚点 / 体感 / 水位 / 斜率 / 中枢 / 穿越周期 / 价值回归 / 认知 / 心智 / 势能 / 动能 / 变量 / 增量 / 存量 / 结构性 / 系统性 / 趋势性 / 周期性 / 边际 / 拐点 / 窗口期 / 新常态 / 高质量发展 / 转型升级 / 提质增效。

**处理**：换成具体的东西。
- 赋能 → 帮 / 给……提供
- 抓手 → 办法 / 入口
- 闭环 → 转起来 / 完整流程
- 生态 → 圈子 / 上下游
- 链路 → 链条 / 流程
- 颗粒度 → 细到什么程度
- 对齐 → 商量一致 / 统一
- 沉淀 → 积累 / 留下
- 复盘 → 回看 / 总结
- 打法 → 做法
- 底层逻辑 → 真正原因
- 长期主义 → 看长期
- 不确定性 → 说不准 / 风险
- 范式 → 做法 / 模式
- 维度 → 角度 / 方面
- 张力 → 矛盾
- 叙事 → 说法 / 故事
- 锚点 → 参照
- 体感 → 感受
- 水位 → 水平
- 斜率 → 速度
- 中枢 → 中心 / 均值
- 变量 → 因素
- 增量 / 存量 → 新增 / 现有
- 结构性 → 具体说哪一块
- 边际 → 新增的 / 一点点
- 拐点 → 转折
- 窗口期 → 时间窗口

## D. 万能副词 / 形容词（没有信息量）⚠️

显著 / 明显 / 大幅 / 持续 / 不断 / 进一步 / 有效 / 充分 / 深入 / 全面 / 系统 / 科学 / 合理 / 精准 / 高效 / 稳健 / 强劲 / 疲软 / 温和 / 严峻 / 复杂 / 多元 / 丰富 / 深刻 / 重大 / 关键 / 核心 / 重要 / 必要。

**处理**：换成数字或删。
- 显著上涨 → 涨 3.2%
- 大幅下跌 → 跌 15%
- 持续收紧 → 连续 17 个月没动
- 有效 → 管用 / 删
- 充分 → 删
- 深入 → 删
- 全面 → 删

## E. 对仗 / 排比 / 公式句（AI 最爱）⚠️

不是……而是……、既……又……、不仅……而且……、一方面……另一方面……、与其……不如……、越是……越……、只有……才……、只要……就……、正因为……所以……、之所以……是因为……、无论……都……、看似……实则……、表面……实际……、短期……长期……、微观……宏观……、机会……风险……。

**处理**：拆成两句，只留一半。
- 改前：这不是一次普通回调，而是一次结构性出清。
- 改后：这不是普通回调。是成长股在出清。

## F. 空话套话（放之四海皆准）

在……背景下、随着……的发展、近年来、当前、如今、毋庸置疑、不可否认、毫无疑问、可以预见、势必、将会、有望、或将、进一步推动、有效提升、充分发挥、不断优化、持续完善、切实加强、深入推进、全面贯彻、落地见效、形成合力、协同发力、多点开花、稳步推进、有序推进。

**处理**：全删。直接说时间、主体、动作、数字。

## G. 翻译腔 / 名词化 ⚠️

进行、实现、具有、存在、具备、开展、推进、落实、构建、打造、营造、助力、基于、针对、关于、对于、鉴于、由于、为了、以便。

**处理**：换成动词。
- 进行讨论 → 讨论
- 实现增长 → 涨了
- 具有优势 → 更好
- 存在风险 → 有风险
- 构建体系 → 搭起来
- 助力增长 → 拉动

## H. 夸张 / 标题党（少量可以，堆就是 AI）

震撼、炸裂、颠覆、史诗级、王炸、核弹、血洗、崩盘、暴雷、疯狂、沸腾、狂欢、至暗时刻、生死局、大奇迹日、绝地反击、彻底变天、历史性时刻。

**处理**：只留 1 个，最好换成数字。

## I. 结尾套话

让我们拭目以待、时间会给出答案、未来可期、值得期待、你怎么看、欢迎留言讨论。

**处理**：换一句具体判断，或直接停。

## J. 标点与格式病

- 破折号 `——` 每 500 字不超过 1 个；
- 分号堆叠：一段里不超过 1 个；
- 括号解释：一段里不超过 1 个；
- "：一是……二是……三是……"：换成自然分段；
- 每段都以"这意味着"收尾：删；
- 三连排比：最多两连；
- 每节都总结：只留开头和结尾总结。

## K. 快速替换表

| 别写 | 写成 |
|---|---|
| 显著提升 | 涨了 X% |
| 大幅下降 | 跌了 X% |
| 持续收紧 | 连续 X 个月没动 |
| 在一定程度上 | 删 |
| 从数据上看 | 删 |
| 整体来看 | 删 |
| 相对而言 | 删 |
| 值得注意的是 | 删 |
| 换句话说 | 重说 |
| 综上所述 | 删 |
| 首先/其次 | 分号、分段、序号 |
| 因此/所以 | 删，句子并排 |
| 本质上 | 说白了 |
| 核心在于 | 关键是 / 删 |
| 随着…… | 删，直接说时间 |
| 在……背景下 | 删，直接说事 |

# 怎么写（去 AI 味的操作手册）

> 核心：**写事实，不写评价；写动作，不写状态；写数字，不写形容词。**
> 写完后用 `kit/check_ai.py` 扫一遍，分数压到 3 以下再发。

## 1. 动笔前：先攒三样东西

1. **三个数字**：最能说明问题的数（涨跌幅、点位、概率）。
2. **一句判断**：全文只留一句结论，能当标题。
3. **一个反常识点**：读者以为 A，其实是 B。

没有这三样，别写。写了也是水。

## 2. 标题

- 给结论，不卖关子：`A股这轮底，大概率在 3200–3420`
- 带数字：`498 条检验，411 条通过`
- 带冲突：`人家打了个喷嚏，我们进了 ICU`
- 不用：浅析、探析、思考、观察、解读、盘点、一文读懂。

## 3. 开头（三行内给完答案）

四种写法，选一种：

**A. 数字开场**
> 5月13号，上证 4242.57。10月30号，3599.02。跌 15%。

**B. 场景开场**
> 群里还在聊 5000 点。五个月后，上证收在 3599。

**C. 反常识开场**
> 纳指同期只跌 0.82%。创业板跌 44.79%。

**D. 对话开场**
> "底在哪？"  
> "3200–3420。"

不要写：随着……、近年来……、在……背景下……。

## 4. 段落

- 一段 1–3 句，最多 5 行；
- 一段只讲一件事；
- 第一句是结论，后面是证据；
- 段尾不总结，直接下一段。

## 5. 句子

**动作句**：主语 + 动词 + 对象。
> 美联储加息。美债收益率上行。成长股杀估值。

**数字句**：把形容词换成数。
> 不写"大幅下跌"，写"跌 15%"。
> 不写"显著提升"，写"从 22.6% 升到 56.0%"。

**判断句**：一句一个判断，不解释。
> 这不是全球风险出清。是 A 股成长股在还债。

**删字**：的、了、着、过、进行、实现、具有、存在、有效、显著、进一步、持续、不断、充分、深入、全面，能删就删。

## 6. 数字

- 数字后面带单位、口径、时间；
- 大数字用"万/亿"，别堆零；
- 区间用"–"：`3200–3420`；
- 概率和分位数分开说：`中位 3413`、`80% 区间 2907–3623`、`5% 分位 2907`。

## 7. 小标题

用句子，不用名词。

- ✅ 这轮跌的，不是"大盘"
- ✅ 底不是一个数，是一个分布
- ✅ 这个区间怎么来的
- ❌ 市场分析 / 结论 / 数据说明

## 8. 幽默

- 只放 2–3 处，放在转折处；
- 自嘲、反差、具体，不写网络烂梗；
- 例：
  > 人家打了个喷嚏。我们直接进 ICU。
  > 跟算命摊差不多。还不用担责任。
  > 之前降了那么多次，怎么还跌。

## 9. 结尾

- 一句话判断 + 一个动作；
- 不写"拭目以待""未来可期""欢迎留言讨论"；
- 例：
  > 底不是一个能算出来的日期。是一组能观测、能催化、能证伪的条件。
  > 三个月后回来对答案。错了认，对了别吹。

## 10. 改稿五遍

1. **删 meta**：先说/本文/下面/接下来/值得注意/换句话说/综上；
2. **砍连接词**：首先/其次/因此/然而/但是/此外/同时；
3. **拆长句**：超过 40 字就断；
4. **具体化**：每个形容词换成数字或例子；
5. **朗读**：读着拗口就改。

## 11. 改前 / 改后（20 例）

| 改前 | 改后 |
|---|---|
| 随着美联储重启加息，美债收益率显著上行，成长股估值因此承压。 | 美联储重启加息。美债收益率上行。成长股杀估值。 |
| 值得注意的是，创业板跌幅明显大于主板。 | 创业板跌 44.79%。上证跌 15%。 |
| 本文试图从因果推断的角度分析底部问题。 | 底在哪。下面用 10 万条路径算。 |
| 综上所述，我们认为市场已处于底部区域。 | 点位 3200–3420。时间 20–90 个交易日。 |
| 首先，从数据层面看，样本区间为 2010 年至今。 | 数据从 2010 年开始。4084 个交易日。 |
| 一方面，外部风险仍在；另一方面，国内政策有对冲空间。 | 外面还在加息。国内还有降准空间。 |
| 这一现象背后存在深刻的结构性原因。 | 原因不复杂。成长股太贵。 |
| 该指标具有显著的领先性。 | 这个指标领先 3 个月。 |
| 我们进行了深入的分析与讨论。 | 我们算了 10 万条路径。 |
| 市场情绪整体较为谨慎。 | 成交额缩到 1.2 万亿。 |
| 政策有望进一步发力。 | 下一个窗口是 11 月 LPR。 |
| 在多重因素叠加影响下，市场出现调整。 | 加息、油价、杠杆，三件事一起上。 |
| 公司实现了营收的快速增长。 | 营收涨了 32%。 |
| 这对市场形成了有效支撑。 | 上证在 3200 附近止跌。 |
| 从长期来看，价值终将回归。 | 三年后，估值回到 20 倍。 |
| 毋庸置疑，这是一次历史性机会。 | 机会有多大，看这五个指标。 |
| 让我们拭目以待。 | 三个月后回来对答案。 |
| 综上所述，本文认为…… | （删掉，直接说结论） |
| 首先/其次/最后 | 01 / 02 / 03 |
| 不是普通回调，而是结构性出清 | 不是普通回调。是成长股在出清。 |

## 12. 自检 20 问

1. 第一段有没有"本文/先说/下面"？
2. 标题是不是结论？
3. 前三屏有没有给完答案？
4. 有没有连接词？
5. 有没有"不是……而是……"？
6. 有没有三连排比？
7. 每段超过 5 行了吗？
8. 每句超过 40 字了吗？
9. 形容词有没有换成数字？
10. 有没有"显著/大幅/持续/不断/进一步/有效/充分"？
11. 有没有"赋能/抓手/闭环/生态/链路/颗粒度/对齐/沉淀"？
12. 有没有"进行/实现/具有/存在/开展/推进/落实"？
13. 小标题是句子还是名词？
14. 每节是不是只讲一件事？
15. 图上的字手机能看清吗？
16. 结论有没有重复三遍？
17. 结尾有没有"拭目以待/未来可期"？
18. 朗读一遍，拗口吗？
19. 删掉 30% 后意思变了吗？没变就删。
20. 像不像人话？

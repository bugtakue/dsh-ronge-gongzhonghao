# 微信公众号粘贴与兼容

## 1. 正确流程

1. Chrome 打开生成的 HTML；
2. `⌘A` 全选，`⌘C`；
3. 公众号后台 → 新建图文 → 正文区 `⌘V`；
4. 检查图片是否自动上传；
5. 标题、摘要、封面在后台单独填；
6. 手机预览，确认字号、行距、图。

## 2. 结构检测报 `text-align: start/end`

原因：浏览器默认对齐值被微信按 `start/end` 判定。

处理：

- 生成器已给所有元素补 `text-align:left`；
- 若仍报：点"继续插入"即可，手机端显示正常；
- 彻底绕开：用 mdnice / wechat-format 导入 Markdown 再复制。

## 3. 图片裂开

- 微信有时不接收 base64 图；
- 手动上传 `figs/` 里的 750px 图；
- 图片顺序与文中 `图 01`–`图 06` 对应。

## 4. 样式被吃

- 公众号会过滤部分 CSS（flex、grid、伪元素、复杂选择器）；
- 本技能生成器只使用 section/p/span 的内联样式；
- 若仍丢失，降级为"加粗 + 下划线"或把重点句做成图片。

## 5. 太长

- 超过 8000px 就砍；
- 方法段并成一段；
- 图从 8 张减到 6 张；
- 目标 2500–3000 字。

## 6. 回退方案

| 问题 | 回退 |
|---|---|
| 编辑器吃样式 | mdnice / wechat-format |
| 图片总裂 | 长图推送（整篇转一张 PNG） |
| 结构检测不通过 | 点"继续插入"，或长图 |
| 手机排版错乱 | 检查是否用了 flex/grid，改块级 |
